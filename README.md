# Case Cracker
Predict outcomes based on historical data! Hosted live at [casecracker.onrender.com](https://casecracker.onrender.com) - though it may take a minute to load up.

## Running the App
Run the app locally using Streamlit.

1. Get the code:

   ```sh
   git clone https://github.com/hto-projects/CaseCracker.git
   ```

2. Get [`uv` installed](https://docs.astral.sh/uv/getting-started/installation/)

3. Get the virtual environment setup

  ```sh
  uv venv

  .venv/bin/activate
  ```

4. Get all the dependencies installed in the virtual environment

  ```sh
  uv sync
  ```

5. Run the app:

  ```sh
  streamlit run
  ```

>_**Note:** Make sure to run command line utilities as an administrator so that they work properly. For Windows users, it may be required to switch between Powershell and Git Bash._
